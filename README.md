# zufallsgruppen

Eigenständiges Browser-Tool aus der Sammlung AM-Tools.

## Starten

Öffne index.html direkt im Browser. Für den Start ist kein Build-Schritt erforderlich.

## Gemeinsame Startseite

Die gemeinsame Startseite wird im separaten Repository amtools verwaltet. In der lokalen Gesamtsammlung und auf dem bisherigen Webserver liegt dieses Tool im Unterordner zufallsgruppen.
